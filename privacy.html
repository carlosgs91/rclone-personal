Privacy Policy

This application is used privately to synchronize personal files between a local computer and Google Drive using rclone.

Google Drive access is used only for file synchronization and backup.

The application does not operate a server that collects or shares user data. Files are handled by rclone on the user's computer and stored in the user's Google Drive.

The user can revoke access at any time through their Google Account security settings.

This policy applies to the personal use of this application.
